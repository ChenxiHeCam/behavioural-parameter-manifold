# Third-party models and licenses

The repository's MIT license covers this study's code and does not replace upstream licenses.

- BAAIWorm: https://github.com/Jessie940611/BAAIWorm, Apache License 2.0. Upstream license text is retained as `BAAIWorm.txt`. Model archives preserve source headers; the headless adapter includes study-specific changes.
- flyvis: https://github.com/TuragaLab/flyvis. Upstream license text is retained as `flyvis.txt`; checkpoint identity is recorded with the model metadata.
- Other simulator dependencies and biological datasets retain their original licenses and manuscript citations.

Source archives remain byte-identical so original provenance hashes can be checked. License notices accompany those historical archives here.
